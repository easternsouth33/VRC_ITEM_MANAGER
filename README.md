# VRC素材整理（vrc-asset-library）

本地 VRChat 素材整理工具：扫描本地素材文件夹或拖入压缩包，自动匹配 BOOTH 商品、
按规则分类、标记关键词、管理集合与网络下载任务，并内置 BOOTH 浏览器。
